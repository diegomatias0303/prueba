# Mi_Proyecto_Principal - Juego de Lotería Mexicana

Este repositorio contiene un juego interactivo de Lotería Mexicana con un sistema de autenticación (Registro y Login) implementado en PHP.

## Características
- **Juego Interactivo**: Lotería Mexicana.
- **Autenticación**: Registro de nuevos usuarios e inicio de sesión.
- **Base de Datos**: Almacenamiento seguro de credenciales de usuario (SQL).

## Instrucciones de Instalación y Uso (Servidor Local)
1. Asegúrate de tener instalado un entorno de servidor local con PHP, como **XAMPP**, **WAMP** o **MAMP**.
2. Copia la carpeta de este proyecto dentro del directorio público de tu servidor.
3. Inicia los servicios de **Apache** y **MySQL**.
4. Abre tu navegador web e ingresa a la dirección local correspondiente.
5. Usa el archivo database.sql o setup.php para crear e inicializar la base de datos necesaria.
6. Navega hacia las pantallas de login o registro para probar la autenticación y jugar.
